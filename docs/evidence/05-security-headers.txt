KIEM TRA:
  [co ] Content-Security-Policy      -> chan inline script, script ngoai
  [co ] X-Content-Type-Options       -> nosniff
  [co ] X-Frame-Options / frame-ancestors -> chong clickjacking
  [co ] Referrer-Policy: no-referrer
  [   ] X-Powered-By -> KHONG CO (dung: da an cong nghe backend)

--- Chi nhan Content-Type JSON cho request thay doi du lieu ---

a) Qua WAF: CRS chan truoc khi request toi app
$ curl -X POST http://localhost:8080/api/auth/login -H "Content-Type: text/plain" -d "x"
   HTTP 403  <- ModSecurity chan (lop 1)

b) Goi thang app, bo qua WAF: app tu tu choi
$ docker compose exec app node -e "fetch(... Content-Type: text/plain ...)"
   HTTP 415 {"error":"JSON_ONLY"}  <- app tu choi (lop 2)

Hai lop doc lap cung chan mot loai request: day la vi du nho
cua Defense-in-Depth. Cung voi cookie SameSite=Strict, viec chi
nhan application/json la lop chong CSRF: form HTML cua site khac
khong gui duoc Content-Type nay ma khong kich hoat CORS preflight.
